Pricing page review

Select text, draw, or drop a pin on this page. Everyone on the review sees every comment as it is posted, and can reply.

Try it

Run the emulators and this page's server from the repository root:

npx firebase emulators:start --config examples/firebase/firebase.json --only auth,firestore --project demo-annotate
npm start
  1. Open ?emulator=1&author=1: you are the review's author.
  2. Open ?emulator=1 in a private window (a second browser identity): you are a reviewer.
  3. Comment in one window and watch it appear in the other.

Why a private window: annotate keeps one identity per browser, and Firebase's anonymous sign-in is per browser too. author=1 only works against the emulator, which lets this page write the review's member list directly. With a real project, add authors in the console.

Your own project

Edit FIREBASE_CONFIG below, deploy firestore.rules, create annotateReviews/demo with { name, open: true }, then open this page without emulator. Add ?google=1 to sign in with Google instead of anonymously (do that for authors).
